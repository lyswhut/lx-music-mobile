# Harmony 歌曲下载

## 使用方法

1. 在搜索结果、在线歌单、排行榜歌曲或个人列表中打开歌曲的「⋮」菜单，选择「下载歌曲」。本地歌曲不显示下载入口。
2. 选择当前音源与歌曲都支持的音质，点击「下载歌曲」。
3. 首次下载时，系统打开目录选择器。选择「Download / 下载」目录，或其中已有的「LX Music」文件夹。应用保存授权并自动创建 `Download/LX Music`。
4. 保持应用在前台，下载窗口显示已接收大小和进度，可取消。成功文件使用 `歌曲名 - 歌手 [音质].实际格式` 命名；同名文件自动加序号。
5. 在系统文件管理的 `Download/LX Music` 中查看歌曲文件。失败或取消会清理临时文件和未完成的输出文件。

## 实现与范围

- JS 入口 `src/core/download.ts` 独立获取新歌曲地址，显式禁止自动换源，避免下载内容与选择的歌曲不一致；取流不修改当前播放队列。
- `MusicDownload.tsx` 在导航根部挂载，菜单只负责触发统一弹窗。支持简体中文、繁体中文与英文。
- `LXDownload` 通过 JS TurboModuleRegistry → C++ `LXMusicPackage.h` 方法表 → ArkTS `DownloadModule.ets` 调用文件选择器、持久授权和 HTTP 流式读取。
- 下载先写入 cache 下的 `.part`；验证 HTTP 2xx（包括音源常见的 `206 Partial Content`）、长度与音频文件头后再写入公开下载目录。根据实际内容识别 MP3、FLAC、WAV、M4A、OGG、APE、AAC；不把 JSON、HTML 或 HLS 播放列表保存为歌曲。
- 网络请求沿用播放器 User-Agent。当前自定义音源协议提供歌曲 URL；若后续音源要求额外媒体请求头，需要扩展取流返回值与下载接口。
- 第一版支持单首前台下载，不支持下载队列、后台下载、断点续传、HLS 合并或下载记录页。桌面歌词、本地元数据读取与离线播放列表不属于本次改动。
- 手机文件夹授权要求 API 26 或更新版本。系统默认 DOWNLOAD 保存模式生成包名目录，无法设置应用名；本实现再授权下载父目录，并用兼容设备的读写授权在其中创建 `LX Music` 文件夹。取消授权不会启动下载。

## 验证与待测

`node scripts/check-harmony-download.mjs` 模拟 ArkTS 系统依赖并执行真实模块逻辑，覆盖目录校验与授权恢复、文件字节一致、媒体请求头、重名不覆盖、错误响应、非音频、内容截断、复制失败清理、取消与重试、并发限制、格式识别，以及 JS 在授权/取流期间的取消和事件隔离。

2026-10-13 真机已验证选择 Download、创建 `LX Music`、授权重启恢复、完整 MP3 保存与重名加序号。独立诊断使用电脑从用户提供的长青音源取得的《Goodnight Saigon》128k 地址，调用实际 `LXDownload` 保存后用 RNFS 读取文件大小：6,753,244 字节。此验证确认手机文件写入链路；不等于完整应用的「手机取流 → 下载」全流程已经通过。

当前手机请求 `musicserver.haitangw.cc` 在连接阶段超时，原生 HTTP 同样返回 `2300028`，没有收到 HTTP 状态码；电脑同条件 POST 返回 201 和有效音乐地址。用户确认手机未开启 VPN，Wi-Fi 与移动数据对比尚未完成。完整应用的取流超时现在会显示明确提示，不再只显示 `Aborted`，已在真机窗口确认。需在手机网络恢复后继续端到端验收，系统文件管理打开与播放也仍待验证。

授权策略使用 `READ_MODE | WRITE_MODE`；此前包含 `CREATE_MODE` 时真机报 Operation not permitted，移除后授权和创建子目录成功。模拟依赖现在显式提供 CREATE_MODE 并校验策略值，避免缺少枚举值导致测试误通过。授权失败会记录步骤和错误码；原生桥返回普通错误对象时保留其 message。

用户回到设备后可重点测试：

1. 首次授权 Download，下载一首已能播放的歌曲，检查文件位于 `Download/LX Music` 且可用系统播放器打开。
2. 播放歌曲 A 时下载歌曲 B，确认当前播放内容不变。
3. 下载中取消，确认未留下 `.part` 或不完整歌曲；随后可重新下载。
4. 下载同一歌曲两次，确认前一文件未被覆盖。
5. 重启应用后再次下载，确认目录授权保存；撤销权限后确认应用能重新授权。

签名包位于 `harmony/entry/build/default/outputs/default/entry-default-signed.hap`，使用 `hdc install -r` 覆盖安装即可保留应用数据。签名配置与生成产物不提交。
